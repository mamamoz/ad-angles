# Сбор через Apify (для продвинутых)

Apify — сервис со сборщиками данных. Подключается к Claude и Codex как коннектор (MCP) по адресу `https://mcp.apify.com`. Нужен, только если хочется собрать 500+ комментариев автоматически. Основной путь навыка — скриншоты, см. `screenshots.md`.

### Найти видео на YouTube

Актор `streamers/youtube-scraper`:

```json
{
  "searchQueries": ["формулировка проблемы 1", "формулировка проблемы 2"],
  "maxResults": 10,
  "sortingOrder": "relevance",
  "dateFilter": "year"
}
```

Из результата бери видео с наибольшим числом комментариев (`commentsCount`). Стоимость поиска — центы.

### Собрать комментарии с YouTube

Актор `streamers/youtube-comments-scraper`:

```json
{
  "startUrls": [
    { "url": "https://www.youtube.com/watch?v=..." },
    { "url": "https://www.youtube.com/watch?v=..." }
  ],
  "maxComments": 120,
  "sortCommentsBy": "TOP_COMMENTS"
}
```

- `maxComments` — на одно видео. 100–150 хватает: лучшие комментарии самые показательные.
- `TOP_COMMENTS` — сначала комментарии с лайками, это то, с чем согласна аудитория.
- Ограничение бюджета на запуск — не меньше $0,50 (меньше Apify не принимает).
- Цена — около $1,5 за 1000 комментариев. 500 комментариев ≈ $0,75.

Нужные поля из результата: `comment` (текст), `voteCount` (лайки), `replyCount` (ответы), `author`, `authorIsChannelOwner` (ответы автора канала выкидывай), `cid`, `videoId`, `title`.

Ссылка на конкретный комментарий: `https://www.youtube.com/watch?v=<videoId>&lc=<cid>` — используй её для каждой цитаты.

### Собрать Reddit

Актор `trudax/reddit-scraper-lite`: в `startUrls` — ссылки на ветки обсуждений, `maxItems` — 200–400. Цена — около $4 за 1000 записей, поэтому бери только самые живые ветки.

### Форумы, отзывы, vc.ru, Пикабу

Веб-поиск + чтение страницы (WebFetch). Если страница не открывается или комментарии подгружаются скриптом — актор `apify/rag-web-browser` с адресом страницы.

## Перед запуском

Назови человеку план одной строкой: «Соберу ~600 комментариев с 6 видео и 2 веток Reddit, это примерно $1,5. Собираю?» Дождись «да».

## Если Apify нет

Не предлагай его настраивать новичку. Переходи к скриншотам или тексту — см. SKILL.md, шаг 3.

## Сохранение сырья

Сырьё держи в общем списке для разбора (шаг 4). Формат:

```
## <Название источника> — <ссылка> — <сколько комментариев>

- [👍 245] «дословный текст комментария» — <ссылка на комментарий>
- [👍 87] «...» — <ссылка>
```

Ссылка на комментарий идёт в источник цитаты в документе — по ней можно проверить первоисточник.
