# Как установить навык «Рекламные углы»

Работает в Claude (сайт, приложение, Claude Code) и в Codex. Ничего платного подключать не нужно.

## Claude — сайт или приложение

1. Скачай архив `ad-angles.zip`. Не распаковывай.
2. Открой «Настроить» → «Навыки» (в английском интерфейсе: Customize → Skills).
3. Нажми «+» → «Создать навык» → «Загрузить навык» (+ → Create skill → Upload a skill).
4. Выбери архив.

## Claude Code

Если навык уже загружен в Claude на сайте — он подтянется сам. Если нет, отправь в Claude Code сообщение:

> Установи навык из репозитория https://github.com/mamamoz/ad-angles в мои навыки Claude Code.

## Codex

Отправь в Codex сообщение:

> Установи навык из репозитория https://github.com/mamamoz/ad-angles в мои навыки Codex.

## Как запустить

Напиши:

> Найди рекламные углы для моего продукта.
> Продукт: <что продаёшь>
> Аудитория: <кто твои клиенты>

ИИ подскажет, какие видео открыть, и как сделать скриншоты комментариев. Пришлёшь скриншоты — получишь документ: 3 угла для теста, хуки для рилс, рекламы и постов, словарь аудитории и возражения.

Если у тебя подключён браузер (Claude in Chrome) — ИИ может собрать комментарии сам. Если подключён Apify — соберёт сотни комментариев автоматически. Но это необязательно: скриншоты работают у всех.
